# Как выложить трекер тренировок

## Важно понять
У вас есть **2 варианта** публикации:

### Вариант 1 — исходный проект (лучший)
Загружаете на GitHub **весь проект**, потом подключаете **Vercel**.

Загружать нужно:
- `index.html`
- `package.json`
- `package-lock.json` (если есть)
- `tsconfig.json`
- `vite.config.ts`
- папку `src/`
- папку `public/` (если есть)

**Не загружать:**
- `node_modules/`
- `dist/`

После этого:
1. Заходите на vercel.com
2. Входите через GitHub
3. Нажимаете `Add New` → `Project`
4. Выбираете свой репозиторий
5. Нажимаете `Deploy`

---

### Вариант 2 — готовая сборка (один HTML)
Этот проект уже собирается в **один файл** благодаря `vite-plugin-singlefile`.

После команды сборки создаётся файл:
- `dist/index.html`

Его можно:
- открыть прямо в браузере как локальный файл,
- переименовать в `workout.html`,
- загрузить как статический HTML на любой хостинг.

Но для **GitHub + постоянной ссылки** лучше использовать **Вариант 1 через Vercel**.

---

## Что у вас уже работает
- Проект собирается без ошибок
- Готовая сборка создаётся в `dist/index.html`

---

## Если хотите просто быстро загрузить на GitHub
Создайте репозиторий, например:
- `training-tracker`

И загрузите в него **исходники проекта**, а не только один HTML-файл.

---

## Если хотите прямую ссылку
Лучше использовать:
- GitHub — хранение кода
- Vercel — рабочая ссылка на сайт

Пример ссылки:
- `https://your-project.vercel.app`
