# 🥗 Nutri — трекер питания, БЖУ и веса

Приложение для похудения / поддержания / набора массы. React + TypeScript + Vite + Tailwind.

## Что умеет

- **Цель и расчёт нормы.** Пол, возраст, рост, стартовый и целевой вес, активность → BMR (Миффлин–Сан Жеор), TDEE и дневная норма калорий с учётом выбранного темпа (кг/нед). БЖУ считаются автоматически (белок по кг веса, жиры 25–28% калорий, остальное — углеводы) либо задаются вручную.
- **Дневник по дням.** Приёмы пищи со **своим временем** (Завтрак 08:30, Обед 13:30 и т.д.), продукты с граммовкой, кольцо калорий и полосы БЖУ.
- **Копирование приёмов пищи.** Кнопка «→ завтра» в один тап, а также копирование/перенос на любую дату и дублирование внутри дня.
- **Сканер штрихкодов.** Камера (ZXing) или ручной ввод кода → поиск в Open Food Facts. Если продукта нет — карточка заполняется вручную и сохраняется в свою базу.
- **База продуктов.** ~65 предустановленных продуктов + свои и найденные онлайн; поиск, редактирование, удаление.
- **Графики, которые растут вместе с записями.** Вес: факт против плановой траектории от стартового веса + линия цели и прогноз срока. Калории по дням с линией нормы. БЖУ по дням (stacked). Диапазоны 2 недели / месяц / 3 месяца.
- **Данные локально** (localStorage), есть экспорт/импорт JSON.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/index.html (single-file сборка)
```

Для работы камеры нужен HTTPS или localhost.
